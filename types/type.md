One note for each type a schema owns, in the folder its schema declares, with the type's name as its file name. The type's code gives its description and abstract: what the type is for. Its note gives its shape: the template a new note of the type starts from, each part named and defined where it sits, so the template explains the type and nothing sits above it. The two are pieces of one node. No note is of an abstract type, only of the types that inherit it.
