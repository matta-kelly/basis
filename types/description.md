---
type: type
description: "A note that explains one node a source gives: what it is, why, and when to use it. It links to the node, and does not repeat a fact of it."
---
The note of a node in code: a node of a described type comes from a source, and one note of this type describes it. `describes` links to that node, and no two notes describe one node. Use it for a thing that lives in code, such as a capability: the code holds its facts, and this note says what it is for and when to use it. A thing that is only written has its note as its node, of its own type, not this one.
